# Minha-Conveniencia

## 1. Introdução

O Sistema de Estoque e Vendas foi desenvolvido com o objetivo de facilitar a organização de produtos e o controle de vendas. A proposta é reunir informações importantes em uma interface simples, facilitando o acesso aos dados e a realização das operações disponíveis.

O projeto foi desenvolvido individualmente, utilizando HTML, CSS e JavaScript. Durante o desenvolvimento, foram trabalhadas a estrutura das páginas, a aparência do sistema e a programação das funcionalidades.

## 2. Objetivos

O objetivo principal é desenvolver um sistema que auxilie no gerenciamento de produtos, estoque e vendas.

Entre os objetivos específicos estão:

- Organizar as informações dos produtos.
- Facilitar o registro e a consulta de vendas.
- Melhorar a visualização das informações.
- Aplicar conhecimentos de desenvolvimento web.
- Criar uma interface simples e fácil de utilizar.

## 3. Tecnologias utilizadas

**HTML:** utilizado para estruturar os elementos da página, como textos, formulários, campos e botões.

**CSS:** utilizado para definir as cores, os tamanhos, o posicionamento dos elementos e a aparência da interface.

**JavaScript:** utilizado para implementar a lógica do sistema, responder às ações do usuário e realizar as operações programadas.

As três tecnologias trabalham juntas para formar a aplicação web.

## 4. Desenvolvimento do sistema

O desenvolvimento foi dividido em etapas. Primeiro, foi definida a estrutura das páginas com HTML. Depois, foi trabalhada a aparência visual com CSS. Por fim, foi utilizado JavaScript para implementar as funcionalidades.

Durante essa etapa, foi necessário organizar os elementos da interface e verificar se as ações programadas funcionavam corretamente.

O sistema foi planejado para facilitar o uso e tornar as operações de estoque e vendas mais organizadas. As funcionalidades descritas na versão final devem corresponder ao que realmente está implementado no código.

## 5. Funcionalidades

Nesta seção devem ser apresentadas as funcionalidades existentes no sistema, acompanhadas, se possível, de capturas de tela.

As funcionalidades podem incluir:

- Cadastro e consulta de produtos.
- Controle da quantidade disponível em estoque.
- Registro de vendas.
- Consulta de informações sobre as operações realizadas.

**Observação:** manter somente as funcionalidades que estão implementadas e funcionando no projeto.

## 6. Testes realizados

Os testes têm a finalidade de verificar se os recursos do sistema funcionam conforme esperado.

Foram definidos os seguintes testes para a validação:

- Abrir o sistema e verificar se a página carrega corretamente.
- Conferir se os campos e botões respondem às ações do usuário.
- Testar o cadastro de um produto, caso essa função esteja disponível.
- Realizar uma venda de teste, caso essa função esteja disponível.
- Conferir se as informações são apresentadas corretamente após as operações.

Os resultados devem ser registrados após a execução de cada teste, indicando se ele foi aprovado ou se foi necessário realizar alguma correção.

## 7. Dificuldades e aprendizados

O desenvolvimento do projeto permitiu praticar conceitos de HTML, CSS e JavaScript. Também possibilitou compreender melhor como a estrutura, a aparência e a lógica de uma aplicação web se complementam.

Entre os aspectos trabalhados estão a organização do código, a construção da interface e a verificação do funcionamento das operações.

O projeto contribuiu para o aprendizado prático e para o desenvolvimento da capacidade de identificar problemas e buscar soluções.

## 8. Conclusão

O desenvolvimento do Sistema de Estoque e Vendas representa uma aplicação prática dos conhecimentos de programação web.

O projeto tem como finalidade facilitar a organização das informações e demonstrar como HTML, CSS e JavaScript podem ser utilizados em conjunto na criação de uma aplicação.

Como melhorias futuras, podem ser considerados novos relatórios, validações adicionais, recursos de segurança e armazenamento mais robusto dos dados, conforme as necessidades do sistema.
